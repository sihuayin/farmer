## 1. 产品概述

### 1.1 产品定位

一款面向农场主的农场规划工具，帮助农场主以可视化的方式设计农场布局，记录种植/养殖区域，并生成美观的预览页面用于展示和分享。

### 1.2 核心价值

- **可视化规划**：通过网格画布直观地管理农场分区
- **快速上手**：内置预设品种库，无需手动输入
- **便捷分享**：一键导出 PNG 图片，适配微信等社交场景

### 1.3 目标用户

小型农场主、农业爱好者、农场体验园区管理者

## 2. 功能范围

### 2.1 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 农场名称设置 | 用户可为农场设置名称 | P0 |
| 10×10 网格画布 | 100 个可编辑地块，支持点击分配类型 | P0 |

| 数据持久化 | localStorage 自动保存 | P0 |
| 地块编辑 | 点击地块可编辑名称、品种、状态或清空 | P1 |
| 清空农场 | 一键重置所有地块为空地 | P1 |

- 用户系统/登录
- 多设备同步

## 3. 数据模型

### 3.1 区域类型定义

| ID | 名称 | Emoji | 颜色色系 | 包含品种 |
|----|------|-------|---------|---------|
| `vegetable` | 蔬菜区 | 🥬 | 绿色 | 番茄、黄瓜、白菜、萝卜、土豆、茄子、辣椒、西兰花、菠菜、生菜 |
| `fruit` | 水果区 | 🍎 | 橙色 | 苹果、梨、桃、葡萄、草莓、西瓜、橙子、芒果、香蕉、猕猴桃 |
| `grain` | 粮食区 | 🌾 | 琥珀色 | 小麦、水稻、玉米、大豆、花生、红薯、棉花、高粱、燕麦、大麦 |
| `flower` | 花卉区 | 🌸 | 粉色 | 玫瑰、郁金香、菊花、百合、牡丹、兰花、向日葵、薰衣草、樱花、梅花 |
| `poultry` | 家禽区 | 🐔 | 黄色 | 鸡、鸭、鹅、火鸡、鹌鹑、鸽 |
| `livestock` | 畜牧区 | 🐄 | 棕色 | 牛、羊、猪、马、驴、骡 |
| `aquaculture` | 水产区 | 🐟 | 蓝色 | 草鱼、鲤鱼、鲢鱼、鳙鱼、罗非鱼、对虾、螃蟹、黄鳝、泥鳅、鳜鱼 |

### 3.2 数据结构

```ts
// 单个地块
interface Cell {
  id: number;              // 0-99，对应 10×10 网格位置
  zoneType?: string;       // 区域类型 ID，如 'vegetable'
  variety?: string;        // 具体品种名，如 '番茄'
  name?: string;           // 地块自定义名称，如 '1号菜地'
  status: 'empty' | 'planted' | 'harvested';
}

// 农场数据
interface Farm {
  name: string;            // 农场名称
  cells: Cell[];           // 固定 100 个元素
  updatedAt: number;       // 更新时间戳
}

// localStorage Key: 'farmer_farm'
```

## 4. 页面设计

### 4.1 路由结构

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 预览页 | 展示用，可导出 PNG |
| `/editor` | 编辑器页 | 画布编辑 |

### 4.2 顶部导航栏

- 左侧：Logo/标题 + 农场名称（编辑器页可直接点击编辑农场名）
- 右侧：预览页链接 + 编辑器页链接（当前页高亮）

### 4.3 预览页 (`/`)

**布局：**
```
[ 顶部导航栏 ]
[ 农场名称（大标题，居中）]
[ 10×10 网格地图（居中，响应式尺寸）]
[ 图例（横向排列）]
[ 导出 PNG 按钮（右下角固定）]
```

**地块渲染规则：**
- `empty` 状态：浅灰色 `#E5E7EB`，显示空白
- 有内容地块：按区域类型的主色着色，显示 Emoji + 品种名（品种名超长截断为2字）
- 地块悬停：显示 tooltip（完整品种名 + 地块名称）

**图例：** 横向排列所有 7 种区域类型，每项显示：颜色块 + Emoji + 类型名称

### 4.4 编辑器页 (`/editor`)

**布局：**
```
[ 顶部导航栏 ]
[ 左侧工具栏 (240px) ] [ 右侧 10×10 画布 (flex-1) ]
```

**左侧工具栏：**
- 标题：区域类型
- 分类折叠面板：
  - **种植类**（默认展开）：蔬菜区、水果区、粮食区、花卉区
  - **养殖类**（默认展开）：家禽区、畜牧区、水产区
- 每个类型点击后展开品种列表
- 当前选中类型 + 品种高亮（边框+背景色）
- 底部：清空农场按钮（红色，需二次确认）

**右侧画布：**
- 10×10 网格，单元格尺寸约 40-60px（响应式）
- 选中工具后，点击地块：设置该地块类型+品种（涂抹模式）
- 点击已有地块：弹出编辑浮层
- 地块悬停：显示 tooltip

### 4.5 地块编辑浮层

点击已有地块时弹出，内容：
- 地块名称（文本输入，默认填充当前值）
- 品种选择（下拉，从当前类型的品种列表中选择）
- 状态选择（单选：空地 / 已种植 / 已收获）
- 操作按钮：保存 / 删除（清空该地块）

## 5. 视觉规范

### 5.1 整体风格

扁平插画风（Flat Illustration），类游戏地图风格，色块分明，现代简约。

### 5.2 配色方案

清新自然色系，以绿色为主：

| 用途 | 色值 |
|------|------|
| 蔬菜区 | `#4CAF50`（绿色） |
| 水果区 | `#FF9800`（橙色） |
| 粮食区 | `#FFC107`（琥珀色） |
| 花卉区 | `#E91E63`（粉色） |
| 家禽区 | `#FFEB3B`（明黄色） |
| 畜牧区 | `#795548`（棕色） |
| 水产区 | `#2196F3`（蓝色） |
| 空地块 | `#E5E7EB`（灰色） |
| 背景色 | `#F0FDF4`（淡绿色） |
| 文字色 | `#1F2937`（深灰） |

### 5.3 图标规范

所有区域类型使用 Emoji 作为图标，无需额外图标库。

### 5.4 字体

使用系统默认字体栈：`ui-sans-serif, system-ui, sans-serif`

### 5.5 圆角

- 地块圆角：`rounded-lg`（Tailwind 默认）
- 卡片/面板圆角：`rounded-xl`
- 按钮圆角：`rounded-lg`

## 6. 技术方案

### 6.1 技术栈

| 类别 | 技术选型 |
|------|---------|
| 框架 | React 18 + Vite |
| 样式 | Tailwind CSS |
| 路由 | React Router DOM v6 |
| 状态管理 | React useState + Context（简单场景无需 Redux） |
| 数据持久化 | localStorage |
| PNG 导出 | html-to-image 库 |
| 部署 | 静态单页应用（可部署至 Vercel / Netlify / GitHub Pages） |

### 6.2 项目结构

```
src/
├── App.jsx                      # 路由 + Context Provider
├── main.jsx                     # 入口
├── index.css                    # Tailwind 入口
├── components/
│   ├── Navbar.jsx               # 顶部导航栏
│   ├── FarmGrid.jsx             # 10×10 网格（预览/编辑器共用）
│   ├── Cell.jsx                 # 单个地块组件
│   ├── ZoneTypePicker.jsx       # 左侧区域类型选择器
│   ├── VarietyPicker.jsx         # 品种选择浮层（展开列表）
│   ├── CellEditModal.jsx        # 地块编辑弹窗
│   ├── Legend.jsx               # 图例组件
│   └── ExportButton.jsx         # 导出 PNG 按钮
├── data/
│   └── zoneTypes.js             # 预设区域类型和品种数据
├── hooks/
│   └── useFarm.js               # 农场数据 Hook + localStorage 持久化
├── pages/
│   ├── PreviewPage.jsx          # 预览页
│   └── EditorPage.jsx           # 编辑器页
└── utils/
    └── exportPng.js             # html-to-image PNG 导出封装
```

### 6.3 localStorage 策略

- Key：`farmer_farm`
- 值：JSON 序列化的 `Farm` 对象
- 读取：应用初始化时从 localStorage 读取，不存在则创建默认空农场
- 写入：任何地块变更后自动写入 debounce（500ms）

## 7. 用户流程

### 7.1 首次使用

1. 用户打开 `/`（预览页），看到空白的 10×10 网格
2. 点击导航栏"编辑器"进入 `/editor`
3. 在左侧选择区域类型（如"蔬菜区"）和品种（如"番茄"）
4. 在画布上点击地块完成涂抹
5. 重复步骤 3-4 完成更多地块
6. 点击导航栏"预览"回到预览页查看效果
7. 点击"导出 PNG"下载图片分享

### 7.2 再次使用

1. 打开应用，数据自动从 localStorage 恢复
2. 直接进入编辑器继续编辑
